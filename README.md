# Entegrasyon Hub for WooCommerce

Bu proje, WooCommerce tabanlı bir mağazanın çoklu pazaryeri hazırlığını tek panelden yönetebilmesi için başlangıç düzeyi bir WordPress eklentisi sunar.

## Desteklenen pazaryeri profilleri (MVP)
- Trendyol
- Amazon
- Etsy
- Ozon
- Hepsiburada
- Pazarama
- İdefix

## Özellikler
- WooCommerce altında **Pazaryeri Entegrasyon Merkezi** sayfası.
- Pazaryeri bazlı API key + satıcı ID saklama.
- Ürün düzenleme ekranında **Pazaryeri SEO** sekmesi:
  - SEO başlığı
  - Pazaryeri açıklaması
  - Harici görsel URL
  - Kargo şablonu
  - Fatura profili
- Son 25 ürün için tek panelde stok, kargo sınıfı, fatura profili görünümü.

## Kurulum
1. Eklenti dosyalarını `wp-content/plugins/entegrasyon-hub` altına kopyalayın.
2. WordPress yönetim panelinden eklentiyi etkinleştirin.
3. WooCommerce > Pazaryeri Entegrasyon menüsünden ayarları girin.

## Not
Bu sürüm bir **MVP altyapıdır**. Canlı sipariş/stok çift yönlü senkronizasyonu, fatura kesimi ve gerçek API entegrasyonları bir sonraki aşama için hazırlanmıştır.
